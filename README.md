# ПДД Казахстан — учебный тренажёр (RU / ҚАЗ)

Адаптивный сайт для подготовки к теоретическому экзамену по Правилам дорожного движения Республики Казахстан. Работает на двух языках (русский и казахский) и без сборки: это чистые HTML, CSS и ES-модули.

> **Важно.** Сайт предназначен только для обучения. Учебные вопросы **не являются официальной экзаменационной базой СпецЦОН (ХҚКО)**. Правила приведены в кратком учебном изложении. При расхождениях приоритет имеет действующая редакция нормативных актов РК: [Правила дорожного движения, утв. приказом МВД РК от 30.06.2023 № 534](https://adilet.zan.kz/rus/docs/V2300033003) и [Закон РК «О дорожном движении»](https://adilet.zan.kz/rus/docs/Z1400000194).

## Возможности

| Раздел | Что внутри |
|---|---|
| Главная | Описание, кнопки «Изучать правила» / «Начать тестирование», личная статистика, преимущества, быстрые ссылки на темы |
| Правила | 12 тем, оглавление, поиск с подсветкой, избранные разделы, переход к пункту из пояснения к вопросу |
| Тестирование | Экзамен (40 случайных вопросов, таймер 40 мин, пояснения после завершения), обучение по темам, марафон, работа над ошибками, избранные вопросы |
| Прогресс | Решённые вопросы, процент правильных, точность по темам, слабые темы, история тестов, рекомендации, экспорт/импорт/сброс |

Также есть светлая и тёмная темы (по умолчанию берётся системная), переключатель **RU / ҚАЗ** в шапке, нижняя панель навигации на телефоне и управление с клавиатуры (`1–4` — выбор ответа, `Enter`/`→` — следующий вопрос, `←` — предыдущий). Все схемы дорожных ситуаций — оригинальные SVG, которые генерирует `js/illustrations.js`.

## Запуск

```bash
npm start            # http://localhost:8080 (статический сервер без зависимостей)
npm test             # модульные тесты (node:test)
npm run validate     # проверка целостности учебной базы
npm run build:seed   # пересобрать db/seed.sql из data/*.json
```

Сайт можно разместить на любом статическом хостинге, например на GitHub Pages. Если открыть `index.html` напрямую как файл, данные не загрузятся: браузер блокирует `fetch` для `file://`.

## Структура

```

js/views/*.js         страницы

```

### Модель данных

Каждая сущность хранится отдельно от своих переводов, поэтому новый язык добавляется без изменения схемы.

- `topics` → `topic_translations`
- `legal_sources` → `legal_source_translations`: нормативный акт и ссылки на «Әділет»
- `rule_sections` → `rule_section_translations`: раздел ПДД, его название и ссылка на раздел акта
- `rule_items` → `rule_item_translations`: пункт в учебном изложении. Поля `clause_number` и `is_verified` нужны для сверки с официальным текстом
- `questions` → `question_translations`: текст и пояснение. Флаг `is_official = FALSE` по умолчанию
- `answer_options` → `answer_option_translations`: варианты ответа, признак `is_correct`
- `question_rule_refs`: связь вопроса с пунктами правил
- `illustrations`: параметры SVG-сцены (JSON)
- `users`, `test_sessions`, `test_answers`, `favorite_*`: прогресс для будущей серверной версии (сейчас он хранится в `localStorage` в той же структуре)

### Как добавить вопрос

1. Добавьте объект в `data/questions.json`. Поля `text`, `options[].text` и `explanation` заполняются на `ru` и `kk`, в `refs` указываются id пунктов из `data/rules.json`.
2. Если нужна иллюстрация, задайте `illustration`. Типы: `sign`, `light`, `intersection`, `road`, `stop`, `crosswalk`, `triangle` (примеры есть в базе).
3. Выполните `npm run validate && npm test`.

## Ограничения и что нужно сверить

- Ссылки даны на **разделы** ПДД РК (например, «раздел 10 „Скорость движения“»). Номера подпунктов не проставлены: при подготовке официальный текст на adilet.zan.kz был недоступен из среды разработки. Перед публичным запуском сверьте формулировки и заполните `clause_number` / `is_verified`.
- Казахский перевод выполнен для учебных целей. Терминологию стоит вычитать носителю языка и сверить с официальным казахским текстом ПДД.
- Рекомендации по первой помощи (СЛР 30:2, жгут) — общепринятые учебные рекомендации, а не текст ПДД. В интерфейсе это указано.
- Критерий «сдан» в учебном экзамене (≥ 85 %, настраивается в `data/meta.json`) — учебный и может не совпадать с официальным.
